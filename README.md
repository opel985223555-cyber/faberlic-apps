# Все мои приложения в одной ссылке

## Загрузка на GitHub Pages
1. Распакуйте ZIP.
2. Откройте репозиторий GitHub → Add file → Upload files.
3. Загрузите все файлы из папки, включая index.html, PNG и шрифт. Файл index.html должен находиться в корне репозитория.
4. Нажмите Commit changes.
5. Откройте Settings → Pages → Build and deployment.
6. Выберите Deploy from a branch, ветку main и папку / (root), нажмите Save.
7. После завершения публикации адрес появится в Settings → Pages.

## Ссылки на приложения
Кнопки пока показывают уведомление: адреса скачивания ещё не добавлены.

Использованы оригинальные PNG и присланный Gotham Pro Medium. Изображения и шрифт лежат рядом с index.html; внешние библиотеки не нужны.
